# OwlPods 🦉🎧

Компаньон для AirPods в GNOME Shell: анимированная карточка в стиле iOS/macOS при открытии кейса и подключении, индикатор заряда в верхней панели и автоматическая пауза музыки, когда вы достаёте наушник из уха.

Поддерживает **AirPods Pro 3** и все остальные модели AirPods, передающие Apple proximity-маячки по BLE.

## Возможности

- **Анимированная карточка-попап** — плавная пружинная анимация появления в стиле iOS/macOS:
  - стиль `ios` — всплывает по центру снизу экрана;
  - стиль `macos` — баннер в правом верхнем углу под панелью;
  - клик вне карточки закрывает её, есть автоскрытие через заданное время.
- **Заряд всех трёх элементов** — кольца с процентами для левого, правого наушника и кейса (включая значок «⚡» при зарядке кейса).
- **Индикатор в верхней панели** — режимы «наименьший заряд», компактный и только иконка.
- **Попап на открытии кейса** и **попап на подключении** — включаются по отдельности.
- **Автопауза по датчику уха** — при извлечении наушника ставит медиа на паузу через MPRIS, возобновляет при установке обратно.
- **Уведомления о низком заряде** — на 20 % и 10 %.
- **Отбор устройств** — можно работать только с выбранным набором (по MAC) и отсекать чужие AirPods вокруг по порогу RSSI.
- **Демо-анимация** — кнопка в настройках и в меню панели для проверки попапа без наушников.

## Как работает заряд

Процент батареи приходит из **Apple proximity-маячков** — недокументированных BLE-пакетов производителя, которые наушники и кейс рассылают, когда крышка открыта (а наушники — и когда они вне кейса). Стандартный GATT Battery Service у AirPods закрыт Apple, поэтому BlueZ полезных значений оттуда не возвращает.

Из этого следуют особенности поведения:

- заряд виден, когда маячки приходят: кейс открыт / наушники рядом;
- пока маячков нет (кейс только открылся) карточка показывает «--», проценты появляются в момент первого пакета;
- распознавание «своих» наушников идёт по **model id из маячка** (у AirPods Pro 3 это `0x2720`), MAC-адрес наушников для этого не нужен: Apple использует ротационные адреса (RPA), которые меняются;
- подключение из карточки всегда ведёт к **сопряжённому набору**, выбранному в настройках.

## Требования

- GNOME Shell **51.x** (протестировано на 51.1, GJS 1.90.1)
- BlueZ 5.x с BLE-сканированием (`bluetoothctl show` → адаптер с LE)
- Linux с Wayland-сессией

## Установка вручную

```bash
git clone https://github.com/Leonid-Perkin/OwlPods.git
cd OwlPods

# дать каталогу имя, совпадающее с uuid расширения
cp -r . ~/.local/share/gnome-shell/extensions/owlpods@leonidperkin

# скомпилировать схему настроек
glib-compile-schemas ~/.local/share/gnome-shell/extensions/owlpods@leonidperkin/schemas
```

Затем **выйдите из системы и войдите снова** (Wayland кеширует модули GJS — без перелогина код не подхватится) и включите расширение:

```bash
gnome-extensions enable owlpods@leonidperkin
```

## Сборка zip (build.sh)

Скрипт собирает оба формата в `dist/` (нужны `glib-compile-schemas` и `python3`):

```bash
./build.sh
```

- `dist/owlpods-vN.zip` — ручная установка: внутри архива папка `owlpods@leonidperkin/`, распаковывается сразу в каталог расширений;
- `dist/owlpods-ego-vN.zip` — формат для загрузки на [extensions.gnome.org](https://extensions.gnome.org): `metadata.json` лежит в корне архива (сайт отклоняет архивы с папкой-обёрткой).

Проверка:

```bash
gnome-extensions info owlpods@leonidperkin
```

## Первый запуск

1. Откройте настройки расширения (через Extensions / Приложения) — внизу появится список найденных Bluetooth-устройств.
2. Выберите свои AirPods — их MAC и имя сохранятся, попапы с чужих устройств больше не будут мешать.
3. Откройте кейс рядом с компьютером — появится анимированная карточка; наушники подключаются автоматически, если Bluetooth считается их доверенным устройством.

## Настройки (gsettings)

Все настройки меняются через окно настроек расширения либо напрямую через `gsettings` (схема `org.gnome.shell.extensions.owlpods`):

| Ключ | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `selected-device-mac` | строка | `""` | MAC выбранного набора (заполняется из списка в настройках) |
| `selected-device-name` | строка | `""` | Человекочитаемое имя выбранного набора |
| `only-selected-device` | булево | `false` | Игнорировать маячки чужих AirPods, если выбран набор |
| `rssi-threshold` | int | `-70` | Порог силы сигнала в dBm: пакеты слабее порога считаются «чужими» (−100…−35) |
| `popup-style` | строка | `"ios"` | Позиция карточки: `ios` (снизу по центру) или `macos` (справа сверху) |
| `popup-duration` | int | `5` | Секунды до автозакрытия карточки |
| `show-popup-on-open` | булево | `true` | Карточка при открытии кейса рядом |
| `show-popup-on-connect` | булево | `true` | Карточка при подключении наушников |
| `show-panel-indicator` | булево | `true` | Индикатор заряда в верхней панели |
| `panel-display-mode` | строка | `"lowest"` | Режим панели: `lowest` / `compact` / `icon` |
| `ear-detection-pause` | булево | `true` | Пауза медиа при извлечении наушника (MPRIS) |
| `low-battery-notification` | булево | `true` | Уведомления на 20 % и 10 % |
| `trigger-demo` | int | `0` | Счётчик-триггер демо-анимации (для тестов) |

## Диагностика

Если что-то работает странно, журнал даёт точные причины:

```bash
journalctl --user -b | grep OwlPods
```

Полезные строки: `Target beacon: …` (принятый маячок с RSSI и зарядом), `Popup rate-limited (N s since last)` (попап подавлен 10-секундным кулдауном), `Target-model beacon too weak: RSSI …` (пакет слабее порога), `Discovery stopped by another component, restarting` (скан был остановлен и перезапущен watchdog'ом), `Connect error: …` (не сработало подключение с кнопки).

## Известные ограничения

- **Заряд кейса при закрытой крышке не обновляется** — закрытый кейс не рассылает маячки (это ограничение протокола Apple, а не расширения).
- `%` батареи появляется только после первого принятого маячка в сессии.
- При отсутствии подключённого набора карточка показывается маячкам моделей AirPods поблизости (можно отключить `show-popup-on-open` и оставить только подключение).

## Структура кода

```
extension.js                     — точка входа: enable/disable, связывание сервисов
prefs.js                         — окно настроек (список устройств, стиль, демо)
src/bluetoothService.js          — BlueZ D-Bus: скан, реестр устройств, маячки,
                                   семейные адреса, watchdog сканирования
src/proximityParser.js           — парсер 27-байтовых Apple proximity-пакетов
src/models.js                    — база моделей AirPods (model id → название)
src/popupCard.js                 — анимированная карточка (Clutter/St, GNOME 51)
src/animatedBatteryRing.js       — кольца заряда с процентами
src/indicator.js                 — индикатор верхней панели
src/mediaController.js           — пауза/возобновление медиа через MPRIS
schemas/                         — GSettings-схема
assets/                          — иконки
```
